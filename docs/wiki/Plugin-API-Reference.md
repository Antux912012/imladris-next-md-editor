# Plugin API Reference

Inside every extension's isolated `JSC.Context` virtual machine, Imladris injects the global host bridge object **`imladris`**.

---

## 1. `imladris.ui` (Interface Bridge)

The UI bridge exposes methods to trigger native Libadwaita notifications and controls without injecting raw DOM elements or custom GTK widgets.

### `imladris.ui.showToast(message)`
Fires a native `Adw.Toast` on the active window's `Adw.ToastOverlay`.
* **Parameters**:
  * `message` *(string)*: Text content of the notification.
* **Example**:
  ```javascript
  imladris.ui.showToast("Analysis completed successfully!");
  ```

### `imladris.ui.addRibbonButton(id, label, icon, callback)`
Adds a native Libadwaita tool button with a Papirus symbolic icon to the **Extensions** group in the Home Ribbon.
* **Parameters**:
  * `id` *(string)*: Unique identifier for the button within this extension.
  * `label` *(string)*: Text displayed next to the icon.
  * `icon` *(string)*: Papirus symbolic icon name (e.g. `alarm-symbolic`, `edit-find-symbolic`, `x-office-document-symbolic`).
  * `callback` *(Function)*: JavaScript function executed when the user clicks the ribbon button.
* **Example**:
  ```javascript
  imladris.ui.addRibbonButton("format-table", "Format Table", "view-grid-symbolic", function() {
      const selected = imladris.editor.getSelectedText();
      if (selected) {
          imladris.editor.insertAtCursor(`\n| Column 1 | Column 2 |\n| :--- | :--- |\n| ${selected} | Value |\n`);
          imladris.ui.showToast("Converted selection to Markdown table.");
      } else {
          imladris.ui.showToast("Please select text first.");
      }
  });
  ```

## 2. `imladris.editor` (Editor & Buffer Bridge)

> [!IMPORTANT]
> Requires `"editor"` permission declared in `manifest.json`. If called without permission, the call is blocked and a permission denial warning toast is displayed.

### `imladris.editor.getText()`
Returns the complete plain text content of the active document's `GtkSource.Buffer`.
* **Returns**: `string`
* **Example**:
  ```javascript
  const doc = imladris.editor.getText();
  console.log(`Document contains ${doc.length} characters.`);
  ```

### `imladris.editor.getSelectedText()`
Returns the currently highlighted text selection in the active editor buffer, or an empty string if no selection exists.
* **Returns**: `string`
* **Example**:
  ```javascript
  const selection = imladris.editor.getSelectedText();
  if (selection.length > 0) {
      imladris.ui.showToast(`Selected: ${selection.substring(0, 30)}...`);
  }
  ```

### `imladris.editor.insertAtCursor(text)`
Inserts text at the current cursor position in the active buffer. Automatically grouped in a user action block (`begin_user_action()` / `end_user_action()`) so users can undo or redo the insertion seamlessly with `Ctrl+Z` / `Ctrl+Shift+Z`.
* **Parameters**:
  * `text` *(string)*: Text string to insert.
* **Example**:
  ```javascript
  imladris.editor.insertAtCursor("<!-- Generated by Plugin -->\n");
  ```

## 3. `imladris.repl` (R and Python Execution Bridge)

> [!IMPORTANT]
> Executing R or Python requires `"repl_r"` or `"repl_python"` declared in `manifest.json`.

### `imladris.repl.runR(code)`
Dispatches R code to the persistent interactive R session. Output is routed to the active document's console log.
* **Parameters**:
  * `code` *(string)*: R command or script string.
* **Example**:
  ```javascript
  imladris.repl.runR("summary(mtcars); cat('\\nAnalysis complete.\\n')");
  ```

### `imladris.repl.runPython(code)`
Dispatches Python code to the persistent interactive Python / IPython session.
* **Parameters**:
  * `code` *(string)*: Python statement or block string.
* **Example**:
  ```javascript
  imladris.repl.runPython("import pandas as pd; print(pd.__version__)");
  ```

## 4. `imladris.elrond` (Local AI Copilot Bridge)

> [!IMPORTANT]
> Requires `"elrond_ai"` permission declared in `manifest.json`.

### `imladris.elrond.ask(prompt)`
Submits a prompt to the active Elrond Assistance engine (local Vulkan/CPU `llama-server` or configured endpoint) and displays the assistant side panel.
* **Parameters**:
  * `prompt` *(string)*: Instruction or question for Elrond.
* **Example**:
  ```javascript
  imladris.elrond.ask("Explain the residuals from this linear regression model: summary(fit)");
  ```

## 5. GNOME Libadwaita HIG Design Rules for Plugin Authors

To preserve the native desktop feel of GNOME:
1. **Never Inject Raw HTML/CSS**: All UI controls must be requested through `imladris.ui`. This ensures full adherence to system fonts, high-DPI scaling, and accessibility features.
2. **Use Symbolic Papirus Icons**: Always specify symbolic icon names ending in `-symbolic` (e.g. `document-save-symbolic`, `edit-cut-symbolic`, `media-playback-start-symbolic`). Symbolic icons recolor dynamically to match light and dark themes.
3. **Respect Permissions Minimization**: Only request permissions your plugin genuinely needs. Requesting unnecessary permissions causes users to scrutinize the installation dialog.
